# 16- and 32-pixel sub-spans on the GPU, 2026-11-04

Step 6, item 4. Step 5 ported Turbulent8 (water, 16-pixel sub-spans) and the
sky (32-pixel sub-spans) into the software reference and left the GPU shaders
perspective-exact per pixel. The shaders now cut each scanline run into the
same sub-spans.

## Which sub-spans does the software path use? (bibliography)

- `reference/common/d_init.c` `D_SetupFrame` (line 139): `D_DrawSpans` is
  `D_DrawSpans16` only under `USE_X86_ASM` and `d_subdiv16` (default 1);
  otherwise `D_DrawSpans8`. The engine's reference is the C path, so
  **world faces use 8 pixels** (already on the GPU since #63). There is no
  32-pixel span for world surfaces.
- `d_scan.c` `Turbulent8` (line 198 on): `r_turb_spancount = 16`, `s` and `t`
  from a divide at the start, at `+ 16` while more follow (step
  `(snext - s) >> 4`) and at `+ count - 1` for the last (step divided by
  `count - 1`), the end value limited to `[16, bbextents]`, the start masked
  to `(TURB_CYCLE << 16) - 1`.
- `d_sky.c` `D_DrawSkyScans8` (line 63): `SKY_SPAN_SHIFT` 5, spans of 32, the
  same scheme with no clamping.

So 16 (water) and 32 (sky) are the sizes in use at 320 x 200 and 1280 x 800;
the 16-pixel world spans of the x86 assembly are not what the engine's
reference runs, and are not ported.

## What the shaders do now

`render/gpuworld/special.go`: each face's world-space polygon is in a new
storage buffer (`Special.FaceVerts`, with its first vertex and count in an
80-byte face record). The fragment shader projects the polygon (the
reference's near-plane clamp), finds the scanline run at its row (first pixel
`ceil(xl)`, last `floor(xr)`) as `FillTurbulentQuake` and `FillSkyQuake` do,
takes its sub-span from `(px - first) / 16` (or 32), evaluates `s` and `t`
exactly at the sub-span's start and end, and steps them in integers. In the
water shader the start of every sub-span after the first is limited as its end
was, and the start is masked before stepping, as in the C.

integers at a few starts. Not chased further at 0.11 % unexplained.
